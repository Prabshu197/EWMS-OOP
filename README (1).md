## Project Overview

The **E-Waste Management System** is a console-based application developed in **C++** using Object-Oriented Programming principles. It helps manage electronic waste records by allowing users to add, display, search, update, and delete e-waste information. The system also provides recycling guidance and calculates reward points to encourage responsible disposal of electronic waste.

## Features

- Add new e-waste records
- Display all records
- Search records
- Update existing records
- Delete records
- Device-specific recycling guidance
- Reward point calculation
- Summary of total items and weight
- File handling for permanent data storage
- Exception handling for input validation
